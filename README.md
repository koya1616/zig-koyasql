# zig-koyasql

SQL tooling written in Zig.

## Requirements

- [Nix](https://nixos.org/) with flakes enabled (optional, for the dev shell)
- [direnv](https://direnv.net/) (optional)

## Development

Enter the dev shell (provides Zig and ZLS):

```sh
direnv allow   # or: nix develop
```
